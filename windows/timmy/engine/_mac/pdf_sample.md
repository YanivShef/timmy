# הצעת מחיר לאתר חנות

**תאריך:** 2026-11-17 10:30 · **אורך:** 24:18 דק׳ · **עם:** [[דנה כהן]]

## סיכום

דנה מנהלת סטודיו לקרמיקה ורוצה חנות אונליין במקום המכירות דרך האינסטגרם. דיברנו על **אתר ב-Shopify** עם 40 מוצרים בהתחלה, סליקה ומשלוחים. יניב הציע לבנות את החנות בעזרת Claude Code ולחבר אוטומציה שמעדכנת מלאי מהגיליון שדנה כבר מנהלת.

הוסכם שהמחיר יהיה 6,500 ₪ כולל חודש תמיכה, ושהעבודה תתחיל אחרי שדנה תשלח תמונות ותיאורים.

## נקודות עיקריות

- דנה מוכרת היום רק דרך הודעות באינסטגרם, וזה גוזל לה שעתיים ביום
- רוצה חנות שעולה לאוויר לפני עונת החגים
- חשוב לה שהעיצוב יהיה נקי ויתאים לסטודיו
- יש כבר גיליון מלאי מסודר ב-Google Sheets
